# Ask & Negotiation Cheatsheet

## Opening ask
**$24,000 USD** for the full asset package (see ASSET_INVENTORY.md).

## Ranges
| Buyer offer | Your move |
|-------------|-----------|
| <$10k | Decline or fire-sale only if you need cash this week |
| $10k–$14k | Counter $20k; floor $12k |
| $15k–$19k | Counter $22k; accept ≥$18k if clean escrow + fast close |
| $20k–$24k | Accept if transfer terms clean |
| >$24k | Great — take it |

## Value talking points (true)
- Live Stripe checkout + 525 engines + 4 Modes — not a template site
- Ad money paths already built (`/go/*`)
- Platform / FAQ / brand / Modes pages = buyer-ready trust layer
- Rebuild would cost far more than ask (agency $40k–$120k) — you’re selling time-to-market

## Don’t overclaim
- No ARR multiple until revenue exists
- No “guaranteed” traffic or virality
- No court-ready / funded-grant promises

## Deal structure
- 100% via Acquire/Flippa escrow
- 50/50 only if you strongly trust buyer (generally avoid)
- Include 7-day transfer support; extra consulting = $150/hr or fixed SOW

## After first revenue
Re-list or re-ask using **24–36× monthly profit** once you have 2–3 months of clean Stripe payouts.
